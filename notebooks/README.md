# Notebooks

This directory contains Jupyter notebooks for exploration, analysis, and modeling.

## Notebooks

- **eda-fraud-data.ipynb**: Exploratory Data Analysis for fraud dataset
- **eda-creditcard.ipynb**: Exploratory Data Analysis for credit card dataset
- **feature-engineering.ipynb**: Feature engineering and preprocessing
- **modeling.ipynb**: Model training and evaluation
- **shap-explainability.ipynb**: Model interpretability using SHAP
